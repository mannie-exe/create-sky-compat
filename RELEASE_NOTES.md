# Skyweave: Compatibility Patches 0.20.1

Correct the mod-list name, configuration heading, built-in resource descriptions, diagnostics, release title, and documentation. The mod ID, package, config filenames, feature switches, and behavior remain unchanged from 0.20.0.

Existing 0.20.0 worlds retain their registry identity. Worlds created with Create Sky Compat 0.19.0 or earlier still require their original release; this update does not convert them or bypass the generation guard.

Build/package checks and disposable dedicated-server startup are verified in [verification](docs/development/verification.md). Interactive client rendering was not rechecked for this text-only update.

Previous release: [0.20.0](docs/releases/0.20.0.md).
