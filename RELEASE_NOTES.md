Initial beta for Minecraft 1.21.1 / NeoForge, Sky Archipelago 1.3.6 and Sky Villages 1.0.6.

- Keep new Sky Villages beside island terrain with a configurable horizontal gap
- Reject overlapping footprints and villages without a substantial nearby island
- Configure through a TOML file or NeoForge's built-in config screen
- Preserve existing villages, layouts, loot and other structure types

Filtering reduces the number of villages. It does not guarantee a count per cluster.
