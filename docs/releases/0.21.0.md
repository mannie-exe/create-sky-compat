# 0.21.0

Assemble qualified shaders on clients from verified installed inputs. The shared
Java engine supports the BSL/Colorwheel overlay and Complementary/Euphoria/
Skyweave chain, with deterministic output, cache integrity, atomic publication
and scoped Euphoria scanner coordination. Compat settings show recipe status and
provide an explicit rebuild action. Recipes and upstream shader binaries are
supplied separately; no shader or patcher is embedded in this mod.

Include the completed Create Tiled Glass/pane backfaces and touching-surface
separation. Stable adaptations default on when dependencies and physical side
qualify; explicit false selections remain authoritative. Preserve existing
Skyweave generation identity without treating an unrelated historical marker as
an automatic conversion or rejection policy.

See [verification](../development/verification.md) for actual native scope and
remaining renderer limits, and [rendering](../development/rendering.md#shader-assembly)
for ownership and dependency-update procedures.
